# macOS 권한 상태 조회 검증

관련 이슈: #3, #6. 작업 범위는 설정 화면의 macOS 권한 조회 상태와 재조회입니다.
다른 세션은 서명·패키징, 실제 업데이트 설치, Windows 실기기 검증,
AI 연결·추론 속도 비교를 독립적으로 진행할 수 있습니다.

## 확인할 동작

- 최초 조회가 끝나기 전에는 권한 거부로 표시하지 않습니다.
- 조회 실패와 권한 거부를 구분하고, 사용자가 다시 확인할 수 있습니다.
- 창에 돌아오면 다시 조회하고, 이전 조회가 늦게 끝나도 최신 결과를 덮지 않습니다.
- Windows에서는 macOS 전용 권한 영역을 표시하지 않습니다.
- 상태 조회는 권한 요청이나 TCC 설정 변경을 실행하지 않습니다.

## 검증 현황

- 변경 전 TypeScript 검사와 프런트엔드 테스트 7개 통과.
- 변경 전 Swift 테스트는 로컬 Command Line Tools의 XCTest 모듈 부재로 실패.
- 구현 후 브라우저에서 모의 IPC로 조회 중·실패·거부·허용·재조회 순서를 검증할 예정입니다.
- 실기기 업데이트 후 권한 유지와 실제 선택 읽기·캡처는 이 문서의 자동 검사 범위 밖입니다.
