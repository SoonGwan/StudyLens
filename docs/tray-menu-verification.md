# 트레이 메뉴 검증 (2026-10-11)

## 변경

- macOS 상태 아이콘: AppKit의 `moon.fill`을 2배 해상도로 렌더링한 템플릿 이미지. 밝고 어두운 메뉴바에서 시스템이 색상을 결정한다.
- 일반 클릭: 제공된 집중 모드 메뉴의 크기·배치·색상을 참고한 308×314pt 팝오버. StudyLens 표시를 남기며 항목은 실제 macOS 집중 모드 설정으로 연결한다. OS 집중 모드를 직접 변경하거나 실제 활성 상태를 주장하지 않는다.
- Option 클릭: StudyLens 기능·진행 상태·설정·종료 메뉴(344×390pt). 누르는 시점 또는 떼는 시점의 Option 상태를 사용한다.
- Windows: 일반 클릭으로 StudyLens 기능 메뉴. 기존 우클릭 네이티브 메뉴는 유지한다.
- 팝오버는 Escape, 바깥 클릭으로 인한 포커스 상실, 메뉴 작업 선택 시 닫힌다.

## 통과한 검사

- `bun run test`: 프론트엔드 4개, Rust 60개, Swift 13개, 도우미 프로토콜 7개 통과.
- Rust 테스트에 일반/Option 클릭 모드 선택과 실제 시스템 심볼 PNG의 크기·투명도·가시성 검사를 추가했다.
- 실제 트레이 React 페이지를 로컬 Vite 서버 + headless Chromium에서 검사했다. Tauri IPC만 가짜 상태/이벤트로 대체했으며 실제 계정과 요청은 사용하지 않았다.
- 집중 모드 항목 8개, 일반↔기능 메뉴 전환, 기본 메뉴에서 불필요한 앱 설정 조회 없음, 설정/코드/취소 IPC, Escape, 작업 중 기능 비활성화, 페이지 오류 없음 확인.
- 두 창 크기에서 모든 버튼 경계가 화면 안에 들어가는지 검사하고 2배 해상도 스크린샷을 확인했다. 하단 설정 줄 잘림과 종료 버튼 줄바꿈을 수정했다.
- macOS ARM64 릴리스 앱과 DMG 빌드.

## 별도 실기기 확인 필요

자동화 환경은 메뉴바 클릭을 지원하지 않는다. 위 웹 화면 검사와 모드 선택 단위 테스트는 실제 상태 아이콘의 클릭이나 macOS 네이티브 반투명 효과 검증을 대체하지 않는다. 설치 앱에서 일반 클릭/Option 클릭, 바깥 클릭 닫기, 실제 집중 모드 설정 연결을 확인해야 한다. Windows와 서로 다른 배율의 다중 모니터는 실기기 검증 전이다.
