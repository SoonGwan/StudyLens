# 영역 캡처 → 코드 클립보드

## 동작

- 새 액션 `capture-code`, 기본 단축키 macOS `⇧⌘7` / Windows `Ctrl+Shift+7`. 설정에서 변경 가능.
- 단축키를 먼저 누르고 문제 영역을 드래그한다. 텍스트 선택·손쉬운 사용 권한·`그림 첨부` 체크는 필요 없다.
- 선택한 PNG 한 장만 코드 생성 요청에 보낸다. ChatGPT·API 키·Claude Code 각각 기존 연결을 사용한다.
- 완료된 응답의 유효한 코드 블록 하나만 공용 복사 경로에서 추출한다. Markdown·설명은 복사하지 않고 줄바꿈·들여쓰기는 유지한다.
- 성공·실패 시 결과 창을 자동으로 열지 않는다. 상태와 오류는 Option-클릭 기능 메뉴에서 확인한다. 필요할 때만 최근 결과를 수동으로 연다.
- Esc, 요청 취소, 잘못된 이미지, 연결 실패, 코드 없음/불완전한 블록/여러 블록은 앱의 코드 복사를 실행하지 않는다. 취소 검사와 클립보드 쓰기를 같은 요청 잠금 안에서 수행한다.
- macOS 캡처는 `screencapture -i -s -x -t png`로 영역 드래그만 허용한다. 시스템 캡처기의 Control-클립보드 옵션은 누르지 않는다.
- 기존 텍스트 → 코드 단축키와 사용자 설정은 유지한다. 이미지에 언어가 없으면 설정의 기본 코드 언어를 사용한다.

## 자동 검증 (2026-10-11)

- 프론트엔드 7, Rust 67, Swift 13, helper 프로토콜 7 테스트 통과.
- 신규 Rust 6개: 액션의 무창 실행/초기 단계, 기존 단축키 마이그레이션, OpenAI 두 연결의 코드 프롬프트·정확한 PNG 한 장·추출된 코드 들여쓰기, 잘못된 입력의 네트워크 이전 차단, Claude 이미지 메시지, mock CLI의 이미지 + 코드 프롬프트 실행.
- `tsc --noEmit` 및 Vite 프로덕션 빌드 통과.
- Playwright + mock IPC: 새 메뉴 액션 `capture-code`, 기본 단축키 표시, 작업 중 비활성화, 취소 액션, 344×444 메뉴의 항목 잘림 없음, 일반 집중 모드 메뉴 회귀 검사, 페이지 오류 없음.

실제 Claude 구독·Windows 실행은 이 자동 검증에 포함되지 않는다. 모델이 생성한 코드의 컴파일·정답 여부도 별도 검증이 필요하다.

## macOS 실제 확인 절차

1. 새 빌드를 설치하고 키체인 접근 및 화면 기록 권한을 확인한다. ad-hoc 서명 변경으로 기존 스위치가 켜져 있어도 권한이 유효하지 않을 수 있다.
2. 공개 연습 문제만 보이는 영역에서 `⇧⌘7`을 누르고 문제 영역을 드래그한다.
3. 결과 창이 나타나지 않는지, 메뉴에 복사 완료가 표시되는지 확인하고 별도의 테스트 편집기에 직접 붙여넣는다.
4. 새 캡처를 Esc로 취소한다. 이전 코드가 유지되는지 확인한다.
5. 다른 단축키로 변경 후 실행하고 기존 텍스트 → 코드 기능이 유지되는지 확인한다.
