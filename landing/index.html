01 / 하는 일한 명이 세 가지 일을 합니다.

텍스트든, 그림이든.
막히는 순간에 불러.

다른 창에 옮겨 적을 필요 없이.
지금 보고 있는 곳에서 선택하고,
단축키로 도움을 요청하세요.

01 — TEXT⌘ ⇧ 0

“이 부분, 무슨 뜻인데.”

앱이나 웹페이지에서 텍스트를 선택하세요. 선택한 내용만 읽고 요청에 맞는 설명을 보여줍니다.

드래그 → 단축키 → 설명 확인 → 직접 복사
02 — IMAGE⌘ ⇧ 9

“그림도 가져와.”

텍스트로 옮기기 어려운 도표나 문제는 화면의 필요한 영역만 캡처해 설명을 받으세요.

단축키 → 영역 선택 → 설명 확인 → 직접 복사
03 — CODE⌘ ⇧ 8

“코드는 여기. 붙여넣기는 네가.”

문제를 선택하고 코드 바로 복사를 실행하세요. 복사할 코드를 확정하면 코드만 클립보드에 넣습니다.

드래그 → 단축키 → 코드 자동 복사 → 직접 붙여넣기

기본 단축키는 설정에서 변경할 수 있습니다. 코드 복사는 컴파일이나 정답을 보장하지 않습니다.

이진 탐색은 왜 O(log n)일까?
탐색 범위가 줄어드는 과정을 설명해줘.

⌘ ⇧ 0
학습 설명StudyLens

한 번 비교할 때마다 탐색 범위가 절반으로 줄어듭니다. n개의 원소에서 시작하면 약 log₂ n번 비교한 뒤 하나의 후보만 남습니다.

def binary_search(items, target):
    left, right = 0, len(items) - 1
    while left <= right:
        mid = (left + right) // 2
        if items[mid] == target:
            return mid
        if items[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
내용을 검토한 뒤 복사하세요.

04 / 연결 방식쓰는 계정에 맞게 선택하세요.

연결은 셋.
사용량은 각자의 것.

요청은 선택한 연결의 한도를 사용합니다.
StudyLens가 한도를 추가하지는 않습니다.

01

ChatGPT 구독

Continue with ChatGPT로 로그인합니다. 지원되는 계정의 구독 한도 또는 허용된 크레딧을 사용하며, 계정·워크스페이스 정책에 따라 제한될 수 있습니다.

공식 연동 안내 ↗
02

OpenAI API 키

본인의 API 키를 설정합니다. API 요청 비용은 구독과 별도로 발생하고, 사용하는 모델과 요청량에 따라 달라집니다.

API 요금 확인 ↗
03

Claude Code

이 Mac에 설치하고 로그인한 Claude Code CLI로 연결합니다. CLI의 사용 한도를 공유하며, StudyLens는 Claude 인증 정보를 직접 읽거나 저장하지 않습니다.

사용량·비용 안내 ↗

ChatGPT 한도나 연결 오류가 발생해도 API 키 결제로 자동 전환하지 않습니다. 실제 로그인·구독 요청은 사용자의 계정에서 확인해야 합니다.

05 / 궁금한 것들

잠깐,
이건 알고 가자.

내 화면을 계속 보고 있나요?+

직접 선택한 텍스트나 캡처 영역을 요청할 때만 전송합니다. 선택이 없을 때 페이지 전체를 대신 보내지 않습니다. OpenAI 연결은 Responses API로, Claude 연결은 로컬 Claude Code를 거쳐 전송하며 데이터 처리는 선택한 서비스 정책을 따릅니다.

어떤 권한이 필요한가요?+

선택한 텍스트를 읽으려면 손쉬운 사용(접근성), 영역 캡처에는 화면 기록 권한이 필요합니다. 시스템 설정 → 개인정보 보호 및 보안에서 허용하세요. 업데이트 후 기존 권한이 작동하지 않으면 앱을 종료하고 새 앱을 다시 등록·허용하세요. 권한 안내 ↗

그림과 텍스트를 함께 보낼 수 있나요?+

현재 OpenAI 연결에서는 설정 → 선택 텍스트 입력에서 그림 첨부를 켤 수 있습니다. 텍스트를 읽은 뒤 직접 선택한 그림 영역 한 장을 함께 보냅니다. 기본값은 꺼짐이며 Claude 연결에서는 이 옵션을 지원하지 않습니다.

코드는 자동으로 붙여넣나요?+

코드 바로 복사만 성공 시 코드 하나를 자동 복사합니다. 일반 설명은 결과 창에서 직접 복사합니다. 붙여넣기와 입력은 직접 하며, 코드가 없거나 복사 대상을 확정할 수 없으면 기존 클립보드를 유지합니다.

어떤 앱에서나 동작하나요?+

일부 앱과 보안 입력 영역은 선택 텍스트를 제공하지 않을 수 있습니다. 이때는 영역 캡처를 사용하세요. 단축키 충돌은 설정에서 변경할 수 있습니다. AI 설명과 코드는 직접 검토해야 하며, 진행 중인 시험·감독 환경에서는 정답 대신 개념 복습을 제공하도록 설계되어 있습니다.

Windows 다운로드는 언제 나오나요?+

현재는 macOS SwiftUI 앱을 소스에서 빌드합니다. macOS·Windows용 Tauri 전환은 진행 중이고 공개 바이너리 릴리스와 출시 일정은 아직 없습니다. 전환 현황 ↗ · 릴리스 확인 ↗
