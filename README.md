# StudyLens

[제품 소개 · 사용 흐름 · 설치 안내](https://study-lens.no-money-do-you-have-money.com/)
| [랜딩 개발 안내](landing/README.md)

StudyLens는 macOS 메뉴바에서 실행되는 개인 학습 보조 MVP입니다. 세 가지 입력 방식을 제공합니다.

1. 전역 단축키로 화면 영역을 직접 선택하면 캡처 이미지를 그대로 OpenAI 비전 모델에 보내 단계별 설명을 받습니다.
2. 앱이나 웹페이지에서 텍스트를 드래그한 뒤 별도 전역 단축키를 누르면 선택한 텍스트만 보내 답과 설명을 받습니다.
3. 문제를 드래그하고 **코드 바로 복사** 단축키를 누르면 결과 창 없이 완성된 코드만 클립보드에 넣습니다.

일반 설명은 결과 창에서 복사 버튼을 눌러 복사합니다. **코드 바로 복사**만 성공 시 자동으로 클립보드를 갱신하며, 붙여넣기는 사용자가 직접 합니다.

진행 중인 시험이나 감독 환경에서 몰래 답을 제공하거나, 다른 위젯으로 위장하거나, 답안을 자동 입력하는 기능은 포함하지 않습니다. 분석 지침에도 시험·감독 화면으로 판단되면 정답 대신 일반적인 개념 복습만 제공하도록 명시되어 있습니다.

## 0.2.6 이슈 기반 개선

- **추론 강도:** 설정 → 추론 강도에서 빠르게(low)·균형(medium)·깊게(high)·모델 기본값을 선택합니다. 모델·연결 방식별로 저장하며 요청 시작 시 고정합니다. 지원이 확인되지 않은 모델에는 `reasoning`을 생략합니다.
- **진행과 취소:** 메뉴에서 입력 읽기·그림 선택·연결 준비·응답 대기·작성·복사 단계와 총 경과 시간을 확인하고 현재 요청을 취소할 수 있습니다. 요청 시간 확인에는 첫 SSE 이벤트와 첫 출력 시간이 따로 표시됩니다. 자동 재시도는 하지 않습니다.
- **그림 첨부:** OpenAI 연결에서 설정 → 선택 텍스트 입력에서 첨부를 켜면 텍스트를 읽은 뒤 사용자가 직접 선택한 그림 영역 한 장을 같은 요청에 보냅니다. 추가 지시는 선택 사항입니다. 기본은 첨부 꺼짐입니다.
- **권한:** 설정에서 현재 실행 중인 앱의 접근성·화면 기록 접근 가능 여부와 업데이트 후 복구 절차를 확인합니다. 빌드 시 설치된 서명 인증서를 명시적으로 선택할 수 있습니다.
- **복사:** 단독 Java 원문의 CRLF·주석 처리와 빈 블록 인식을 수정했습니다. Java·Python·C++의 합성 사례 37개를 같은 표시 데이터·전체 복사·개별 코드 복사·자동 복사 경로에 적용합니다. 코드 복사 성공은 컴파일 성공·정답 보장이 아닙니다.

Claude 연결은 기존 기본 추론 설정과 영역 캡처를 유지하며 추가 지시를 지원합니다. 선택 텍스트와 그림을 함께 첨부하는 옵션은 현재 OpenAI 연결에서 지원합니다. Claude는 전체 CLI 결과를 받은 시간을 기록하고 첫 SSE 이벤트 시간은 표시하지 않습니다.

[검증 결과와 남은 실기기 확인](docs/issue-verification.md)에 이슈 #1~#5별 근거와 제한을 정리했습니다. 이 릴리스는 이슈 #6의 Windows/Electron 전환을 포함하지 않습니다.

## 요구 사항

- macOS 13 이상
- Xcode 15 이상 또는 해당 Command Line Tools
- 구독 연동을 지원하는 ChatGPT Plus·Pro 계정, 로그인된 Claude Code(Claude Pro·Max 구독), 또는 OpenAI API 키

## ChatGPT 구독 사용량으로 사용하기

StudyLens 0.2는 공식 **Sign in with ChatGPT**를 사용합니다. API 키 없이 지원되는 계정의 구독 사용량 또는 허용된 크레딧으로 이미지·텍스트 요청을 보낼 수 있습니다. 로컬에서 실행하는 개인 프로젝트를 위한 공식 연동입니다. 현재 계정·워크스페이스·지역 정책에 따라 사용할 수 없을 수도 있습니다.

1. 설정의 **사용 방식**에서 **ChatGPT 구독 사용량**을 선택합니다.
2. **Continue with ChatGPT**를 누릅니다.
3. 브라우저에서 로그인하고 StudyLens가 ChatGPT 구독 사용량을 사용할 수 있도록 허용합니다.
4. 앱으로 돌아오면 해당 계정에서 제공하는 모델 목록이 나타납니다. 원하는 모델을 선택합니다.
5. 캡처 또는 선택 텍스트 단축키로 설명을 요청합니다.

이 요청은 ChatGPT·Codex와 기존 구독 한도를 공유하며 별도 한도를 추가하지 않습니다. [ChatGPT 사용량 설정](https://chatgpt.com/settings/usage)에서 StudyLens의 앱별 한도와 한도 이후 크레딧 사용 허용 여부를 조정할 수 있습니다. 구독 한도 또는 연결 오류가 발생해도 앱은 API 키 결제로 자동 전환하지 않습니다. API 방식은 설정에서 사용자가 직접 선택해야 합니다.

로그인은 기본 브라우저와 로그인 중에만 열리는 `127.0.0.1` 콜백으로 진행합니다. 앱 자체 등록, PKCE, state·nonce 확인, OpenAI 공개 키를 이용한 ID 토큰 서명 검증을 구현했습니다. 다른 앱의 로그인 파일이나 브라우저 쿠키를 읽지 않습니다. 접근·갱신 토큰과 계정별 등록은 키체인에 저장되며, 접근 토큰 만료 시 갱신됩니다. 로그아웃 시 서버의 갱신 토큰 취소를 요청하고 로컬 토큰을 삭제합니다. 네트워크 문제로 서버 취소를 확인하지 못했다면 ChatGPT 설정에서도 연결을 해제해 주세요.

구독용 요청은 공식 `https://api.openai.com/v1/responses`로 보내며 `store: false`, `stream: true`를 적용합니다. 응답 완료 이벤트를 받은 경우에만 결과와 복사 버튼을 활성화합니다.

공식 근거: [연동 개요](https://developers.openai.com/siwc/token-sharing-open-source), [로그인](https://developers.openai.com/siwc/token-sharing-open-source/sign-in), [모델과 추론](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference), [현재 제약](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations).

## Claude 구독 사용량으로 사용하기 (Claude Code)

Anthropic은 서드파티 앱용 구독 로그인(OAuth)을 제공하지 않습니다. 그래서 StudyLens는 Claude 토큰을 직접 다루지 않고, 이 Mac에 설치되어 로그인된 **Claude Code**(`claude` CLI)를 헤드리스 모드(`claude -p`)로 실행해 요청합니다. 요청은 Claude Code와 같은 구독 사용 한도를 공유합니다.

1. [Claude Code](https://code.claude.com)를 설치합니다.
2. 설정의 **사용 방식**에서 **Claude 구독 사용량 (Claude Code)**를 선택합니다.
3. 로그인되어 있지 않으면 **Claude 로그인**을 누릅니다. Claude Code가 브라우저 로그인을 처리합니다. 진행되지 않으면 터미널에서 `claude auth login`을 실행하세요.
4. 모델(Claude Code 기본값·Opus·Sonnet·Haiku)을 선택하고 단축키로 요청합니다.

- `claude` 위치는 `~/.local/bin`, `~/.claude/local`, Homebrew 경로, 로그인 셸의 `PATH` 순으로 찾습니다. 찾지 못하면 설정에 실행 파일 경로를 직접 입력하세요.
- 사용자의 Claude Code 설정·MCP 서버·스킬·도구를 불러오지 않고(`--setting-sources ""`, `--strict-mcp-config`, `--tools ""`), 세션 기록도 남기지 않습니다(`--no-session-persistence`).
- StudyLens는 Claude Code의 인증 정보를 읽거나 저장하지 않습니다. 개인 Mac에서 본인 계정으로 쓰는 용도이며, 다른 사람에게 Claude 로그인을 제공하는 배포용 기능이 아닙니다.

## 앱 번들 만들기 및 설치

가장 권장하는 실행 방법입니다. 프로젝트 폴더에서:

```bash
./build-app.sh
open .build
```

생성된 `.build/StudyLens.app`을 Finder의 **응용 프로그램** 폴더로 옮긴 뒤 실행합니다. 처음 실행할 때 macOS가 개발자 확인 경고를 표시하면 앱을 Control-클릭하고 **열기**를 선택하세요. 기본 빌드는 로컬 실행용 임시(ad-hoc) 서명입니다. 설치된 인증서가 있으면 명시적인 identity를 선택할 수 있습니다.

```bash
./build-app.sh --identity 'Developer ID Application: Your Name (TEAMID)'
# 또는 STUDYLENS_SIGNING_IDENTITY 환경 변수에 같은 identity를 지정
```

명시적인 인증서 서명은 hardened runtime과 timestamp를 사용합니다. 서명을 검증한 뒤 기존 빌드 결과를 교체하며, 공증·인증서 발급·설치는 자동 실행하지 않습니다. `--configuration debug`와 `--output-dir /path/to/artifacts`도 지원합니다. [서명·권한 업그레이드 검증 방법](docs/issue-verification.md#서명과-권한-업그레이드)을 확인하세요.

## 개발 모드로 실행

터미널에서 프로젝트 폴더로 이동한 뒤:

```bash
swift run StudyLens
```

또는 Xcode에서 `Package.swift`를 열고 `StudyLens` 실행 대상을 선택해 실행합니다.

앱이 시작되면 Dock 아이콘 없이 메뉴바에 원형 아이콘만 나타납니다. 메뉴는 `Option(⌥)` 키를 누른 채 아이콘을 클릭해야 열립니다. 기본 단축키는 영역 캡처 `Command + Shift + 9`, 선택 텍스트 `Command + Shift + 0`입니다.

## 초기 설정

1. `Option(⌥)` 키를 누른 채 메뉴바의 StudyLens 아이콘을 클릭하고 **설정…**을 엽니다.
2. **ChatGPT 구독 사용량**을 선택하고 **Continue with ChatGPT**로 로그인합니다. API 키를 쓰려면 **API 키 · 별도 결제**를 선택하고 키를 저장합니다.
3. ChatGPT 연결은 계정에서 제공하는 목록에서 모델을 선택합니다. API 키 방식의 기본 모델은 `gpt-4.1-mini`이며 직접 변경할 수 있습니다.
4. 영역 캡처·선택 텍스트·코드 바로 복사의 **단축키 기록**을 각각 누른 뒤 원하는 조합을 입력합니다. Command, Option, Control 중 하나가 반드시 포함되어야 합니다. 앱 내 중복 조합은 거부하며 전역 등록 실패도 설정에 표시합니다.
5. 캡처 기능에는 화면 기록 권한을, 선택 텍스트 기능에는 접근성 권한을 허용합니다.

개발 중 `swift run`으로 실행하면 macOS가 StudyLens 대신 실행에 사용한 Terminal 앱의 화면 기록 권한을 요구할 수 있습니다. Xcode에서 실행하면 Xcode 권한을 요구할 수 있습니다. 완성된 `.app` 번들로 실행하면 StudyLens 자체에 권한을 부여하게 됩니다. 권한을 처음 변경한 뒤에는 앱을 완전히 종료하고 다시 실행해야 할 수 있습니다.

## 사용 흐름

1. 기본 단축키 `Command + Shift + 9` 또는 설정한 단축키를 누릅니다.
2. 십자 커서로 학습 문제 영역을 드래그합니다. `Esc`를 누르면 취소됩니다.
3. 상태 아이콘이 캡처 중, 분석 중, 완료 상태로 바뀝니다.
4. 결과 창에서 캡처 이미지와 단계별 설명을 검토합니다.
5. 필요한 경우에만 **설명 복사**를 누릅니다. 자동 붙여넣기나 자동 제출은 하지 않습니다.

선택 텍스트 기능은 텍스트를 드래그한 직후 기본 단축키 `Command + Shift + 0`을 누르면 됩니다. 일부 앱이나 보안 입력 영역은 macOS 접근성 API로 선택 내용을 제공하지 않아 동작하지 않을 수 있습니다.

### 0.2.1 선택 텍스트 호환성 수정

- 전역 포커스 요소 하나에 의존하지 않고, 단축키를 누를 당시 앱의 포커스 요소·상위 문서·현재 창에서 선택 영역을 확인합니다. 메뉴를 열 때도 직전에 사용하던 앱을 기억합니다.
- Chromium 브라우저의 문서 선택용 text marker와 일반 앱의 명시적인 선택 범위를 지원합니다. 접근성 정보가 준비되는 동안 짧게 재시도합니다.
- 지원되는 Chromium 브라우저에서는 선택을 읽는 동안 접근성 정보를 요청하고, 변경한 플래그는 읽기 종료 후 이전 값으로 되돌립니다. VoiceOver를 켜거나 브라우저를 재시작하지 않습니다. [Chromium 공식 설명](https://www.chromium.org/developers/design-documents/accessibility/), [Electron 공식 설명](https://github.com/electron/electron/blob/main/docs/tutorial/accessibility.md).
- 비밀번호 영역·숨겨진 영역은 제외하고, 선택이 없을 때 페이지 전체를 대신 전송하지 않습니다. 자동 Command+C나 클립보드 읽기도 하지 않습니다.
- 30,000자를 넘는 선택은 내용을 잘라 보내지 않고 사용자에게 나누어 선택하도록 안내합니다.

업데이트 후 선택 텍스트가 동작하지 않으면 **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 StudyLens를 확인하세요. 임시 서명 앱은 업데이트로 서명이 바뀌어 기존 허용이 유효하지 않을 수 있습니다. StudyLens를 완전히 종료한 뒤 기존 항목을 제거하고 새 앱을 등록·허용한 다음 다시 실행하세요. 화면 캡처 권한은 별도로 유지합니다.

Chrome이 계속 선택 정보를 제공하지 않으면 Chrome의 `chrome://accessibility`에서 현재 탭의 접근성 활성 상태를 확인하거나 영역 캡처를 이용하세요. 이미지·도표는 드래그한 텍스트만으로 전달되지 않으므로 영역 캡처가 적합합니다. 실제 Chrome 선택 → 설명 요청은 사용자가 권한을 허용한 뒤 확인해야 하며 자동 테스트 통과만으로 모든 앱의 호환성을 보장하지는 않습니다.

### 0.2.2 요청에 따른 답변

선택한 텍스트를 사용자 메시지로 그대로 전달합니다. 본문 끝에 “Java 코드로 만들어줘”, “설명만 해줘”, “번역해줘” 등을 함께 선택하면 그 요청의 언어와 형식에 맞춰 답하도록 지시합니다. 고정된 네 단계 목차는 사용하지 않습니다. 그림이 누락되어도 가능한 설명은 먼저 제공하며, 가정이 필요한 경우 가정을 명시합니다. 정답을 결정하는 데 꼭 필요한 정보만 없는 경우에는 추가 정보를 요청할 수 있습니다. 텍스트 선택에는 그림 자체가 포함되지 않습니다.

### 0.2.3 코드 표시와 복사

코드 블록은 설명과 분리하여 고정폭 글꼴로 표시하며 줄바꿈·탭·들여쓰기를 유지합니다. 각 블록의 **코드 복사**, 또는 코드 블록이 하나일 때 하단의 **코드만 복사**를 사용하면 설명·언어 이름·Markdown 구분자 없이 코드 원문만 복사됩니다. **전체 복사**는 응답 원문 전체를 복사합니다. 결과 창에서 코드를 직접 선택해 복사할 때도 줄바꿈을 유지합니다.

저장한 UTF-8 결과 텍스트를 다시 표시하려면 `open .build/StudyLens.app --args --result-file /absolute/path/result.txt`로 실행할 수 있습니다. 이 동작은 AI 요청을 새로 보내지 않습니다.

### 0.2.4 코드 바로 복사

문제나 요청을 드래그한 뒤 기본 단축키 **⌘⇧8**을 누릅니다. 설정의 **코드 바로 복사 → 단축키 기록**에서 다른 조합으로 바꿀 수 있습니다. 기본 코드 언어는 Java이며 설정에서 변경할 수 있습니다. 본문에 “Python으로 만들어줘”처럼 언어를 지정하면 그 요청을 우선합니다.

결과·디버그 창이나 권한 안내 팝업을 자동으로 열지 않습니다. 작성 중 메뉴바 점은 주황색, 복사 완료는 초록색, 실패는 빨간색이며 마우스를 올리면 상태를 볼 수 있습니다. 완료 후 직접 **⌘V**로 붙여넣으세요. 메뉴에서 오류 확인과 결과 열기는 수동으로 가능합니다.

완료된 응답의 닫힌 코드 블록 하나를 복사하며 설명·Markdown 구분자는 제외하고 줄바꿈·탭·들여쓰기는 유지합니다. Markdown 구분자가 생략된 단독 Java 클래스도 시작 구문과 문자열·주석을 제외한 괄호 균형을 확인해 복사할 수 있습니다. 이는 형식 검사이며 컴파일이나 정답 검증은 아닙니다. 구분자 없는 Python·C++ 등 다른 언어의 원문은 자동 복사하지 않으며 결과 창을 수동으로 열어 전체 복사할 수 있습니다. 네트워크 오류, 미완료 응답, 코드 없음, 여러 코드 블록 등 복사 대상을 확정할 수 없는 경우 기존 클립보드를 그대로 둡니다. 자동 붙여넣기·제출은 하지 않습니다.

### 0.2.5 실패 응답과 상태 표시

코드 없음·여러 블록·닫히지 않은 블록·빈 코드를 구분해 안내합니다. 수동으로 결과 창을 열면 실패한 경우에도 AI 응답을 확인하고 전체 응답 또는 완성된 개별 코드 블록을 복사할 수 있습니다. 코드 추출 실패를 사용량 오류처럼 표시하지 않습니다. 상태 점은 문자 색상 대신 색을 가진 이미지로 표시하고 상태·메시지 변경을 함께 관찰합니다. 실패나 성공 시 결과 창을 자동으로 열지 않는 동작은 유지합니다.

## 권한 및 개인정보

- **화면 및 시스템 오디오 기록:** 사용자가 직접 선택한 영역을 캡처하는 데 필요합니다.
- **접근성 권한:** 선택 텍스트를 읽을 때만 필요합니다. 전역 단축키 자체와 캡처 기능에는 필요하지 않습니다.
- **네트워크:** 선택한 이미지 또는 텍스트가 분석을 위해 OpenAI Responses API로 전송됩니다. ChatGPT 로그인은 OpenAI 인증 서버에 연결합니다.
- **API 키:** macOS 키체인의 `com.studylens.api` 서비스에 기기 전용 항목으로 저장됩니다.
- **ChatGPT 로그인:** 같은 키체인 서비스의 별도 항목에 계정별 OAuth 정보를 저장합니다. 이 연결은 기존 ChatGPT 대화나 메모리에 접근하지 않습니다.
- **임시 이미지:** 시스템 임시 폴더에 저장되며 읽은 직후 삭제됩니다. 그림 첨부는 사용자가 직접 선택한 PNG 영역 한 장, 10 MiB 이하만 허용합니다. 실제 PNG 형식·크기·모델의 이미지 지원 여부를 전송 전에 확인합니다.
- **진단:** 모델·강도·연결 방식·단계별 시간만 메모리에 유지합니다. 선택 원문·코드·인증 토큰을 자동 기록하거나 업로드하지 않습니다. 추가 지시와 첨부 선택 설정은 사용자가 설정한 값으로 기기에 저장됩니다.

OpenAI Responses API 요청에는 `store: false`를 설정했습니다. 계정별 데이터 처리 정책과 보존 조건은 OpenAI 플랫폼 설정 및 최신 공식 문서를 함께 확인하세요.

## 빌드와 테스트

```bash
swift build
swift test
```

릴리스 실행 파일만 빌드:

```bash
swift build -c release
```

생성된 실행 파일은 Swift가 표시하는 release 빌드 폴더에 있습니다. 설치형 앱은 위의 `build-app.sh`를 사용하세요. 다른 사용자에게 배포하려면 Developer ID 코드 서명과 Apple 공증을 별도로 설정해야 합니다.

## 주요 구조

- `StudyLensApp.swift`: SwiftUI 메뉴바 앱 및 결과/설정 창
- `AppModel.swift`: 캡처 → 분석 → 확인 → 복사 상태 흐름
- `ScreenCaptureService.swift`: macOS 대화형 영역 선택 캡처
- `InferenceProvider.swift`: 백엔드 공통 인터페이스(`InferenceProvider`)와 공용 프롬프트(`StudyPrompt`)
- `OpenAIService.swift`: Responses API 이미지 분석 (`OpenAIProvider`로 연결)
- `ClaudeCodeService.swift`: 로컬 Claude Code CLI 실행 (`InferenceProvider` 구현)
- `ChatGPTAuthService.swift`: 공식 ChatGPT 로그인, 계정 선택, 토큰 갱신과 로그아웃
- `OAuthLoopbackServer.swift`: 로그인 중에만 열리는 로컬 콜백
- `OIDCIdentity.swift`: 로그인 서명과 계정 정보 검증
- `HotKeyService.swift`: 사용자 지정 전역 단축키
- `KeychainService.swift`: API 키 보관

## 알려진 제한

- macOS의 시스템 캡처 UI를 사용하므로 캡처 중에는 앱 자체 선택 UI를 커스터마이즈할 수 없습니다.
- 전역 단축키가 다른 앱의 단축키와 충돌하면 등록되지 않을 수 있습니다. 이 경우 설정에서 다른 조합을 선택하세요.
- 모델별 이미지 입력 지원과 API 사용 요금은 계정 및 모델에 따라 다릅니다.
- ChatGPT 구독 연동은 계정·워크스페이스의 지원 여부에 따라 제한될 수 있습니다. 모델 목록을 확인하는 것만으로 실제 추론 가능 여부가 보장되지는 않습니다.
- 이 버전은 로컬 빌드와 자동 테스트로 검증했습니다. 실제 사용자 로그인과 구독을 소비하는 요청은 테스트하지 않았으며 사용자가 첫 로그인 후 확인해야 합니다.
